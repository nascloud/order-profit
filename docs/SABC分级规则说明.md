# SABC 分级规则说明

## 1. 分级对象

SABC 是对「商品链接」做经营分级，不是对产品、SKU 或订单分级。

每个链接按 `商品ID` 汇总订单和推广数据后，再生成一个 SABC 等级。报表中的产品分析只统计各产品下面有多少个 S/A/B/C/待核算链接。

## 2. 核心分级指标

SABC 使用链接的「含推广经营贡献利润」分级，不按销售额分级。

```text
含推广经营贡献利润 = 推广前经营利润 - 推广花费
```

推广前经营利润来自订单核算结果，已经扣除对应订单的退款、货品成本、运费、平台扣点、综合税赋、关闭已发货损失等经营成本。

这样可以避免「销售额高但实际亏损」的链接被误判为核心链接。

## 3. 参与分级的前置条件

链接先按核算完整度和利润正负分流：

| 情况 | 等级 | 说明 |
|---|---|---|
| 成本或运费缺失 | 待核算 | 不参与 S/A/B/C 排名 |
| 已核算且含推广经营贡献利润 <= 0 | C | 亏损或无贡献链接 |
| 已核算且含推广经营贡献利润 > 0 | 进入 S/A/B 排名 | 按盈利贡献排序分级 |

`待核算` 链接不会计入盈利链接数或亏损链接数。

## 4. S/A/B 排名规则

所有正利润链接按以下顺序排序：

1. 含推广经营贡献利润从高到低。
2. 利润相同时，按商品 ID 升序。

排序后计算：

```text
单链接盈利贡献率 = 当前链接含推广经营贡献利润 / 全部正利润链接含推广经营贡献利润合计
分级前累计贡献率 = 当前链接之前所有正利润链接贡献率之和
```

默认阈值：

| 等级 | 判断规则 | 经营含义 |
|---|---|---|
| S | 分级前累计贡献率 < 50% | 核心利润链接，重点保障和放量 |
| A | 50% <= 分级前累计贡献率 < 80% | 稳定盈利链接，继续优化增长 |
| B | 分级前累计贡献率 >= 80% | 有利润但贡献较低，控制投入 |

边界按「分级前累计贡献率」判断，所以跨过阈值的那条链接仍归入当前等级。

例如默认 50% / 80% 阈值下：

| 排名 | 链接利润 | 分级前累计贡献率 | 等级 |
|---:|---:|---:|---|
| 1 | 400 | 0% | S |
| 2 | 300 | 40% | S |
| 3 | 200 | 70% | A |
| 4 | 100 | 90% | B |

第 2 条虽然会把 S 的累计贡献推到 70%，但它分级前是 40%，所以仍然是 S。

## 5. C 类规则

已核算完成但含推广经营贡献利润小于或等于 0 的链接，统一标记为 C。

C 类不参与 S/A/B 的盈利贡献率累计，也不会因为销售额高而升级。

## 6. PROVISIONAL 暂算规则

如果整次运行还有成本或运费缺失，报表状态为 `PROVISIONAL`。

此时完整链接仍会计算等级，但显示为：

```text
暂算 S
暂算 A
暂算 B
暂算 C
```

含义是：当前已核算数据下的临时判断，不作为最终经营结论。补齐成本和运费后重新运行，才会生成正式 SABC。

## 7. 自定义阈值

命令行可通过 `--sabc-config` 指定 UTF-8 JSON 配置文件。

默认配置等价于：

```json
{
  "s_profit_share": 0.50,
  "a_profit_share": 0.80
}
```

字段含义：

| 字段 | 含义 |
|---|---|
| `s_profit_share` | S 级的分级前累计盈利贡献阈值 |
| `a_profit_share` | A 级的分级前累计盈利贡献阈值 |

合法范围必须满足：

```text
0 < s_profit_share < a_profit_share < 1
```

配置文件必须且只能包含这两个字段。缺字段、多字段、非数字、NaN、无穷值、越界或顺序错误，都会阻止报表生成。

以下规则不可配置：

- 成本或运费不完整始终为 `待核算`。
- 含推广经营贡献利润小于或等于 0 始终为 `C`。
- 第一个正利润链接因为分级前累计贡献率为 0，始终至少进入 S。

## 8. 报表展示位置

SABC 结果会出现在：

- Excel 的链接分析表。
- HTML 的链接分析表和 SABC 筛选器。
- 经营总览中的 S/A/B/C/待核算链接数量。
- `manifest.json` 的 SABC 配置快照。

Excel、HTML 和运行清单使用同一份聚合结果，口径一致。
