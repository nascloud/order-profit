# 1.清洗规则

1. 删除【订单状态】为【已关闭】且【物流单号】为空的订单
2. 删除【商家备注】中包含【D】的订单
3. 删除【商家备注】中包含大写字母【S】的订单
4. 删除【买家应付货款】严格小于【20元】的订单

以上删除条件独立判断，任意一个条件成立即删除。

# 2. 特殊规则

1. 对于【订单状态】为【已关闭】且有【物流单号】的订单，

不计算销售额，只计算成本+运费，单独放在一个表中

2. 对于【订单状态】为【买家已付款，等待卖家发货】、【卖家已发货，等待买家确认】和【交易成功】的订单，需要计算【退款状态】为【退款成功】的【退款金额】，这种为小额打款售后。待发货订单按商家编码核算货品成本，无物流单号时使用成本编码表标准运费
3. 把没有商家编码的订单，不计入在内，单独放在一个表中给我

# 3. 利润计算

1. 根据【商家编码】和【购买数量】在成本明细表中找到对应的成本+运费
2. 实收金额使用【买家应付货款】计算
3. 日期限制在8-1到8-7日
4. 商品推广报表中8-1到8-7日的【花费】作为推广费用从利润中扣除；推广归因成交金额仅用于投产分析，不重复计入订单销售额

# 4. 输出规则
1. 输出详细的成本利润表
2. 找出影响利润的关键因素和改进方案
3. 输出清晰的汇总表格
4. 输出网页展示各项数据
