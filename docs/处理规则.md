# 订单利润核算处理规则

## 1. 订单范围

按运行参数中的开始日期和结束日期过滤订单付款时间：

```text
开始日期 00:00:00 <= 订单付款时间 < 结束日期后一天 00:00:00
```

纳入经营核算的订单状态：

- 买家已付款，等待卖家发货
- 卖家已发货，等待买家确认
- 交易成功
- 交易关闭但已付款的关闭订单

未付款关闭订单不进入销售、退款、利润或链接经营指标。

## 2. 刷单处理规则

商家备注中命中刷单标记的订单不再粗暴删除。

当前刷单识别：

- 商家备注包含独立的 `D` / `d`
- 商家备注包含独立的 `S` / `s`

与英文或数字相邻时不按刷单处理，避免误判物流单号、英文缩写等普通备注。

刷单识别先于正常订单的商家编码缺失分流。命中标记的正常订单即使商家编码为空，也进入利润核算；货品成本和运费按刷单规则计为 0，不进入待补成本运费表。

刷单订单的金额处理：

| 项目 | 处理方式 |
|---|---|
| 已付款销售额 | 计入 |
| 平台扣点 | 计入 |
| 综合税赋 | 计入 |
| 刷单金额 | 单独展示 |
| 刷单成本 | 等于刷单订单实收金额 |
| 真实销售额 | 扣除刷单金额 |
| 货品成本、运费 | 刷单订单不再重复计入 |
| 经营利润 | 刷单金额不作为利润，按刷单成本扣回 |

核心公式：

```text
真实销售额 = 已付款销售额 - 订单批次成功退款金额 - 刷单金额

含推广经营贡献利润
= 已核算销售额
- 已核算订单批次成功退款
- 已核算货品成本
- 已核算运费
- 已核算刷单成本
- 已核算平台扣点
- 已核算综合税赋
- 关闭已发货损失
- 推广花费
```

## 3. 成本和运费

货品成本优先级：

1. 成本编码表按商家编码精确匹配。
2. 成本编码表无法匹配时，使用人工补充表。
3. 仍无法解析时进入待补成本运费表。

运费优先级：

1. 运费表从 `订单编码` 第一个下划线前提取订单号，汇总该订单各运单的总运费，匹配订单表 `主订单编号`；子单 0 元不会掩盖母单运费。输入与分摊口径以[开发文档第 5.3、7.5 节](订单利润核算标准化程序开发文档.md)为准。
2. 订单号未匹配实际运费时，使用成本编码表中的标准运费；匹配到的实际 0 元不回退。
3. 仍无法解析时，使用人工补充表。
4. 仍无法解析时进入待补成本运费表。

人工补充的成本和运费是订单明细总金额，不再乘购买数量。

## 4. 销售与退款口径

```text
净销售额 = 已付款销售额 - 订单批次成功退款金额
真实销售额 = 已付款销售额 - 订单批次成功退款金额 - 刷单金额
```

订单批次成功退款按原订单付款日期归属，用于订单、每日、产品、链接和利润核算。

期间退款完结金额按售后表退款完结日期归属，只用于财务现金流复核，不与订单批次退款重复相加。

## 5. 推广口径

推广花费从经营贡献利润中扣除。

推广归因成交金额只用于计算推广投产比，不重复计入订单销售额。

```text
推广投产比 = 推广归因成交金额 / 推广花费
```

## 6. 链接 SABC 分级

SABC 按商品链接分级，使用完整核算后的「含推广经营贡献利润」，不按销售额分级。

| 等级 | 规则 |
|---|---|
| 待核算 | 成本或运费缺失，不参与排名 |
| C | 已核算且含推广经营贡献利润 <= 0 |
| S | 正利润链接中，分级前累计盈利贡献率 < 50% |
| A | 正利润链接中，分级前累计盈利贡献率 >= 50% 且 < 80% |
| B | 正利润链接中，分级前累计盈利贡献率 >= 80% |

正利润链接先按含推广经营贡献利润从高到低排序，利润相同按商品 ID 升序。

完整说明见：[SABC分级规则说明.md](SABC分级规则说明.md)。

## 7. 输出规则

程序输出：

- `订单成本利润分析.xlsx`
- `店铺经营复盘.html`
- `manifest.json`
- `待补成本运费.xlsx`，仅在 `PROVISIONAL` 状态下生成

Excel 和 HTML 使用同一份聚合结果，销售额、退款、成本、运费、刷单金额、刷单成本、推广花费和经营贡献利润口径必须一致。
